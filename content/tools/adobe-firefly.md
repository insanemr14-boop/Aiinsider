Firefly is not trying to win a quality shootout. Adobe's bet is that professional buyers care more about whether they can ship the output than whether it wins a side-by-side comparison, and for enterprise marketing departments that has largely been correct.

The integration is the product. Generative fill in Photoshop is used constantly by people who would never open a standalone image generator, because it solves an existing problem — extend this background, remove this object — inside the file they already have open. Vector generation in Illustrator follows the same logic, producing editable paths rather than something to trace.

Where Firefly disappoints is ambitious creative work. Ask for a striking stylized composition and the result is competent rather than memorable. Most professional teams end up using dedicated generators for concepting and Firefly for production editing, which is an entirely reasonable split.
